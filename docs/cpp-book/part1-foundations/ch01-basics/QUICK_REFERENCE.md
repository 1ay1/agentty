## Key Takeaways (One Per Concept)

**1.1:** Types are your first line of defense. Compiler catches bugs before users do.

**1.2:** Choose ownership (values) or borrowing (refs) or nullable (ptrs) based on semantics.

**1.3:** Const-correct code is self-documenting. The compiler prevents accidental mutations.

**1.4:** auto saves typing but don't hide intent. Use `const auto&` for safe iteration.
